EN:
This is the first version of my auto-clicker project. Unfortunately, it ended up drifting too far away from
the specifications outlined in the Requirements Document (CDC).
I have therefore decided to start over on a cleaner and more solid foundation.
However, this beta version is available so that I can present the project, reuse some of the code,
study the different implementation methods, and gather some practical information.

Files reformatted with Claude are available in the Beta/Refactor Claude folder.

How it works :
All files work independently, but variable management in the main file is extremely messy.
As a result, the main file does not work properly. If you want to use the auto-clicker, you need to open the recorder file,
print the output of the Recorder.r______ function (keyboard, mouse, or keyboard-mouse), then copy and paste one or more
of the generated lists into the action section using the Executor.action_______ functions (keyboard, mouse, or keyboard-mouse).
The workflow is essentially the same for the version that was reformatted by Claude.
